## Default Permission

Allows the JS bridge command(s) used by tauri-plugin-mcp's eval-based correlator.

#### This default permission set includes the following:

- `allow-mcp-result`

<tr>

<th>Description</th>
</tr>


<tr>
<td>

</td>

</td>
</tr>

<tr>
