# o8 Spec — cortex-ide

> One-page spec for this repo. Operator edits here. Agents read this on
> dispatch and can write back when they need to record a decision.

## Mission

o8 (formerly Cortex IDE) is the governance layer for autonomous engineering
teams. Approvals, audit, organizational memory, and mobile operator control
across any AI provider. Claude is the orchestrator/brain; Codex is the
workhorse executing tasks in worktrees. Two agent runtimes ship today
(Codex, Claude Code) through a universal CLI-based adapter interface, with
separate desktop and mobile surfaces.

## Active scope

- [ ] Project Panel unification — clicking a project name OR a repo name
      lands in the same panel (project-scoped, with repo as sub-anchor).
- [ ] Agent panel polish — live work stays primary, recently-merged work
      hides behind a collapsible drawer.
- [ ] Continued beautification of the detailed repo / project surface.

## Constraints

- Inline styles only (`style={{ }}`). Never CSS classes for theming.
- Theme tokens (`var(--t-*)`) over hardcoded colors. Glass tints are
  intentional — see `feedback_glass_transparency.md`.
- 800-line file ceiling. Decompose before extending.
- `npx tsc --noEmit` must pass before every commit.
- Themes are LOCKED. Don't touch them without explicit ask.
- Drilldown / kanban surfaces are deferred — keep the timeline + project
  panel chrome visual-only for v1.

## Open questions

- Per-project orchestrator memory + directives (#986) — deferred but on
  the radar for after the panel work.
- o8.md across multiple repos in a project — currently per-repo only.
