## Voice, visual instructions, and task recovery

- Give instructions about marked images in the current chat, with speech and visual context attached to the same request. Continuous screen capture requires macOS 15; image attachments remain available on macOS 14.
- Use an explicitly selected personal OpenAI key for Live voice, or use turn-based conversation with device speech recognition and speech playback around the selected CLI assistant. Ordinary dictation still fills the draft. Managed Live remains a limited pilot.
- Preserve completed work and worker ownership when stopping and retrying tasks. Prepared tasks can start their first managed test without remaining held.
- Wait for active CLI installation before restarting the app, and explain interrupted installation recovery.
- Keep the selected Activity folder and show missing-folder or Git errors without hiding healthy repositories. Transcript-only updates avoid redundant repository refreshes.
- Cache repeated GitHub reads across workspace snapshots, keep historical terminal replies out of shell input, and improve mobile turn choices and incomplete-reply reporting.

Voice and visual instructions remain experimental. Real microphone, capture, playback, and provider recovery depend on the device, permissions, and selected provider.
