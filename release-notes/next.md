# Worker conversations and clearer desktop controls

- Ask the orchestrator to choose suitable workers from the enabled runtime and model pool for each task. Explicit choices remain available.
- Open delegated workers in their own chat panes with the regular composer. Close a pane and reopen the same conversation from its worker card.
- Keep worker cards beside the transcript turn that launched them, return shared worker results to the originating chat, and preserve queued messages in delivery order.
- Correct or stop supported workers from a compact composer control. Open activity only when needed, with readable floating surfaces in All Glass.
- Reorder workspace tabs and sidebar chats, preserve drafts while moving between tools, and open reviews beside the worker that needs attention.
- Open local development servers in Browser, reload the native document and its resources together, and retain readable source-editor recovery.
- Keep hold-to-dictate feedback beside the input through listening, transcription, polishing and delivery. Follow the active input display, and keep the optional resting pill in Voice Settings.

This release carries source, CI and development verification. Broader installed first-run and additional runtime subscription checks retain their existing acceptance work.
