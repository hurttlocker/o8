# Visual instructions

Capture screen records the selected display while you draw and describe a change.
The continuous recording requires macOS 15 or later and Screen Recording access.
o8 still supports macOS 14. On macOS 14, attach an image to your chat and type your
instruction instead. Capture screen checks recording support before it creates
capture files, starts recording, or opens the drawing surface.

Finish native dictation before starting a visual capture. An existing browser
Live conversation can continue during capture.

Reloading or navigating the main workspace stops its capture and releases its
ownership. Interrupted recording and processing files are discarded after their
writers stop. Completed capture packets are retained so a saved chat draft can
continue to use its images.
