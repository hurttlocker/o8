# Symon system-wide fold into o8 — the screen dock + global hotkey + paste-anywhere

**Status:** build spec · 2026-06-08 · grounded against aqua-color v0.1.15 (notch-dock HUD) + o8 @ 0.1.265. Part of Voice Operator #1205. Internal.

**Goal (operator):** copy Symon's *system-wide* dictation into o8 — a floating dock pill at the **top of the screen** (always-on-top), a **global Fn hotkey**, **dictate-into-whatever-app-is-focused**, all working **without o8 open** ("the natural vibe without opening o8"). **Keep the in-window pill** we have (operator likes it) for when o8 *is* focused — both coexist.

**o8 is already ~70% there:** the STT daemon (`stt_engine` in `lib.rs`, spawned in `setup()`, emits `o8:stt-event`), the React dictation layer (DictationHost + DictationPill + useNativeDictation), a **tray** (`lib.rs:2655`), **hide-not-quit** (`CloseRequested`→`prevent_close()`+`hide()`), and shutdown teardown all exist. Four pieces are missing.

## The four added pieces
1. **Overlay dock window** — a SECOND Tauri window labeled **`dock`** (NEVER `main` — label discipline keeps every `main`-keyed system blind to it: dev-mcp `.default_webview_label('main')`, updater, `apply_vibrancy(HudWindow)`, DragDrop bridge, console-error hook all early-return on non-`main`). It loads the bundled-Next loader → a NEW route **`/dictation-pill`** that mounts `DictationPill` standalone (driven by `o8:stt-event`, no composer anchor). Created in `setup()` **after** the Next server is confirmed up (mirror `prewarm_bundled_next_server`). Config mirrors Symon's pill: `transparent/alwaysOnTop/decorations:false/shadow:false/skipTaskbar/dragDropEnabled:FALSE`. Rust setup applies Symon's `clearColor + setOpaque(false) + setLevel(25)` (above the menu bar = level 24) and **top-anchors** it — NOT o8's dark `HudWindow` vibrancy (would gray the light pill). Not globally click-through; the React layer keeps the transparent dead-zone tight.
2. **Global Fn hotkey** — port aqua's `start_fn_key_monitor` into a self-contained `src-tauri/src/fn_hotkey.rs`: raw `CGEventTap` at `CGEventTapLocation::HID` (Sequoia session-tap regression), `FlagsChanged`+`KeyDown`, Fn flag `0x800000`, own thread + CFRunLoop, **`catch_unwind`** around the callback (a panic across the C boundary aborts all of o8 + kills the Node sidecars), `TapDisabledByTimeout/UserInput` re-enable via stored mach port, and the **40ms `CGEventSourceFlagsState` poll fallback** for the dropped Fn-UP. v1 = plain push-to-talk (trim Fn+R/double-tap/Right-Option). **Reuses o8's existing `stt_engine`** (never spawns a second recognizer). Spawn from `setup()` alongside `stt_engine::spawn`.
3. **Paste-into-focused-app** — copy aqua `paste.rs` (~903 lines) wholesale → `src-tauri/src/paste.rs`, rename bundle id → `ai.o8.desktop`. `save_frontmost_app` (at Fn-down, before the dock steals focus) · `gather_window_context` (AX walk via `run_on_main_thread` — feeds `stt::polish` PolishContext's currently-`None` window/selected/ax fields = pure accuracy upgrade) · `smart_activate` · `paste_text` 6-step (snapshot clipboard → write → re-activate saved app → 35ms settle → synthetic Cmd+V CGEvent keycode `0x09` → restore clipboard after 5s w/ changeCount guard).
4. **Background presence** — o8 already hide-not-quit. The ONLY new behavior: dynamic **`set_activation_policy(Accessory)`** when the main window hides (wire into the existing `CloseRequested` handler) + **`Regular`** when the tray re-shows it (existing tray handlers). NOT static `LSUIElement` (that would kill o8's Dock icon permanently — wrong for an IDE). Fn tap + STT daemon + dock window keep the run-loop alive with the main window closed; the tray is the re-entry point.

## Coexistence (keep main window / updater / dev-mcp socket working)
- **Label discipline** (above) is the firewall — the `dock` window is invisible to all `main`-keyed machinery.
- **Activation policy** is the one lifecycle change — centralize it in ONE helper called from a single window-visibility observer (don't scatter Accessory/Regular across `CloseRequested` + 2 tray handlers — see review).
- **Updater**: add a boot-time launch update check from `setup()` so background-only sessions (never open main) still self-update (today the check fires from main's `on_page_load`).
- **Sidecars/sockets untouched**: Node Next + ws-server, the `speech_recognizer` Swift daemon (Fn monitor REUSES it), the dev-mcp Unix socket (`main`-bound) — a new-label window + new CFRunLoop thread collides with none.
- **Signing**: keep o8's own minisign pubkey + `hurttlocker/o8` updater (do NOT copy Symon's `symon://` / updater endpoint). Add `com.apple.security.device.input-monitoring=true` to `entitlements.plist` (WITHOUT it the CGEventTap gets ZERO events under hardened runtime — the iMac-works/MacBook-fails Sequoia bug) + `NSAccessibilityUsageDescription` to `Info.plist`; re-sign via `npm run ship`.

## Corrections the review caught (fix BEFORE the relevant phase)
- **HIGH — polished-text routing is a NEW Rust branch, not a port.** o8's `run_finalize()` only `emit`s `o8:stt-event{polished}`; React routes it to the composer. There is NO Rust paste consumer. Add a Rust `AtomicBool`/`OnceLock` **`system_dictation_origin`** set at Fn-down; inside `run_finalize`, after `polished`: if origin==system → `paste::paste_text(&polished)` and **do NOT** emit-to-composer (emit a silent/dock-only variant so the dock pill can show "done"); if in-window → emit as today. Must not double-fire.
- **HIGH — `objc2`/AppKit/CoreGraphics reverses an explicit o8 invariant** (`Cargo.toml:62` "does NOT pull objc2/AppKit/CoreGraphics — the Swift helper owns all of that"). `paste.rs` + CGEventTap genuinely need them, but they may collide with `window-vibrancy 0.6`'s older `objc/cocoa` stack (two obj-c binding generations = duplicate-symbol/ABI grief). **Phase 0 gate:** `cargo tree -i objc2` / `cargo tree -i objc`, pin to Symon's exact versions, require a clean `cargo build` with both stacks linked; update the `Cargo.toml:62` comment.
- **MEDIUM — `minimumSystemVersion` mismatch** (o8 `10.15`, Symon `14.0`). The objc2 stack + CGEventTap path assume modern macOS. Decide the real floor (likely 12.0+; Symon chose 14.0) or guard every native call — don't ship 10.15 while linking objc2-app-kit 0.3.
- **MEDIUM — activation policy × `tauri-plugin-window-state`**: if main was hidden at quit, window-state may restore it hidden → app boots in Accessory with no window AND no Dock icon = invisible. Centralize the policy + verify the tray survives an Accessory-from-boot and `Show` restores Regular.
- **MEDIUM — one STT daemon, broadcast events → double-render + double-paste.** `app.emit` broadcasts to ALL windows; both the dock route and the in-window DictationHost receive `polished`. Add an **origin discriminator** to the payload (or `emit_to(label,…)`) so the dock ignores in-window events and vice-versa. Correctness, not polish.
- **MEDIUM — paste focus-steal.** The dock window must **never become key** (NSWindow nonactivating / `canBecomeKey=false`) so showing the pill doesn't steal focus from the target app; verify the underlying caret keeps blinking with the pill visible.

## Phased plan (each phase signed-app-verifiable)
- **P0 — Substrate (no behavior):** cargo-tree audit + add macOS crates pinned to Symon's versions; `input-monitoring` entitlement + `NSAccessibilityUsageDescription`; port the permission-query helpers (Accessibility / Input-Monitoring / AppleFn-usage). **Decide `minimumSystemVersion`.** Verify: signed app, TCC prompts appear + persist, clean `cargo build` with both obj-c stacks.
- **P1 — `paste.rs` + context-aware polish (no UI/hotkey):** copy `paste.rs`; wire `gather_window_context` into PolishContext; temp debug command `paste_text('hello')`. Verify: text lands in a focused 3rd-party app, clipboard restored; in-window polish now spells on-screen proper nouns.
- **P2 — Global Fn → paste (no overlay yet):** `fn_hotkey.rs` (HID tap + poll + catch_unwind); Fn-down `save_frontmost_app`+`stt_engine::start`; Fn-up `stop`→ `run_finalize` origin-branch → `paste_text`. Verify: hold Fn in any app, speak, release → polished text pastes there; in-window composer path intact when o8-main focused; no stuck-recording on Sequoia.
- **P3 — Screen-level dock pill window:** `dock` window + `/dictation-pill` route + canvas EQ in React; Rust clearColor/setLevel(25)/top-anchor/nonactivating; origin discriminator so only the dock shows on system Fn. Verify: pill appears top-center over the menu bar, morphs, transparent (no white flash / gray blob), underlying caret keeps focus.
- **P4 — Background presence:** centralized Accessory/Regular policy; boot-time update check; optional autostart toggle. Verify: close main → Dock icon gone, pill+Fn still work; tray Show restores; reboot w/ autostart → pill live at login; updater works background-only.
- **P5 — Polish/onboarding (optional):** native_glass NSVisualEffectView; first-run TCC + AppleFn-nudge wizard; optional Cmd+Shift+Space toggle; MorphOrb later.
