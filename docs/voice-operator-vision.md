# Voice Operator — direct your org by voice, never merge unreviewed

**Status:** feature vision · 2026-06-07 · grounded against the real codebase via an 8-agent design+adversarial pass. Competitor ref: CNVS ([[cnvs_voice_canvas_direction]]). Infra dependency: harness epic #1204. Internal.

Continuous voice in → realtime STT → intent router → the **one conductor** (the orchestrator brain) → governed hands (surface-switch via the window-event bus / `o8_view_*` fallback, work via dispatch/review/approve MCP, questions via Brain Q&A) → spoken TTS read-back. Plus the opt-in **free-flow canvas** arrangement mode (coexists with the tiling default, morphs via framer-motion springs). Desktop-first (Tauri, no Swift rewrite). On-brand with o8's existing "Operator" concept and the **o**.

**The promise, spoken aloud:** *Direct your org by voice — and every merge is still gated.* Voice commands ONE conductor; it never puppets panels. This is the reframe vs CNVS ("ship to production like a psychopath" = ungoverned): every voice action flows through governance.

**Locked decisions honored:** (1) stay Tauri; (2) no draw layer — annotations live in `o8.md`; (3) name = Voice Operator; (4) free-flow is opt-in, tiling stays default, o8's own framer-motion morph; (5) desktop-first, mobile voice is a future Pro story; (6) voice commands ONE conductor, never puppets panels.

> **Blocked on harness epic #1204 Phase 0 (headless verbs).** Voice is a speech front-end over the canonical verb set #1204 exposes (`ground`/`dispatch`/`review`/`approve`/`reject`/`ask`/`switch-surface`/`set-mode`). Phase 0 here is contract-alignment so voice/CLI/MCP share one governed vocabulary and voice never becomes a parallel action plane. If #1204 verbs aren't stabilized, the router targets existing MCP-proxied `/api` routes as the interim contract.

## The loop
1. **Voice in (conductor mode).** Upgrade `DictationHost` + `useDictation` from single-shot to a continuous session segmenting on the free RMS VAD in `runRafLoop`. Push-to-talk unchanged.
2. **STT (two-tier, cost-controlled).** Free `webkitSpeechRecognition` finals for command-class utterances (zero network); **Gemini Live** (BYOK) for accuracy-critical briefs; `/api/dictation/transcribe` Whisper as fallback.
3. **Intent router** (`src/lib/voice/intent-router.ts`, invoked from the `DictationHost.start` onComplete/onSegment seam ~89-109): deterministic (extend `src/lib/dictation/voice-commands.ts`) → OpenRouter-pool fuzzy (#1123) → default-brief. **Never** calls Anthropic directly.
4. **Conductor (single brain).** Every brief = ONE `ThoughtsChatPanelHandle.sendNow` → `useOrchestratorStream.send(message, { permissionMode, thinkingEffort, model, swarm })`. The brain grounds → dispatches → reviews → gates → answers.
5. **Governed hands.** Surface-switch via the window-event bus (`o8:select-workspace-scope`, `o8:set-orchestration-mode`, `o8:resolve-blocker`, `o8:open-browser`, `o8:open-pr`, `o8:load-history-thread`) + `o8_view_*` (Rust-side) fallback. Work via gated `/api` routes the MCP handlers proxy to: `create_mission` → `dispatch_mission`, `o8_merge_preview` → `submit_review`, `approve_and_merge`/`o8_approve`/`o8_reject` (`operator-handlers/approve.ts` — returns `{ merged:false, blockers[] }`). Questions via `cortex_ask` → `/api/cortex/ask/answer`.
6. **TTS read-back.** Existing `ttsEngine` (`src/lib/tts/engine.ts`) speaks SHORT status/confirmations. On `approve_and_merge {merged:false, blockers[]}` it speaks the blocker and never claims success.

## Voice-edge hardening (blocking, folded in from the adversarial review)
- [ ] **Full-duplex / barge-in + echo cancellation (CRITICAL).** `getUserMedia` is `{audio:true}` with NO echo cancellation today and zero barge-in/duck handling. Required: echo/noise/AGC flags; mic-ducking while TTS plays; barge-in (speech-onset during playback → `ttsEngine.stop()`). v1 = gated path; true barge-in (server-VAD) in P3.
- [ ] **Spoken-confirm + undo for destructive verbs (CRITICAL).** The gate protects bad *merges*, not the operator never intending to approve. Two-utterance protocol for `approve`/`merge`/`reject`/`reset`/`dispatch-to-main`: readback exact action+target → ~8s timeout → only a deterministic `confirm` token (in `voice-commands.ts`, no LLM) executes; `cancel that` aborts an in-flight dispatch pre-spawn. State which actions are NOT undoable.
- [ ] **Confidence + clarify branch (HIGH).** Router gains a `confidence` field + `kind:'clarify'`: fuzzy-match spoken repo/packet/PR refs against live inventory (repos registry, lanes, open PRs); below threshold or >1 candidate → speak the candidate list. Deixis (`this`/`the diff`) binds to the focused packet/PR via window-event scope state.
- [ ] **Activation model + degrade matrix (HIGH).** v1 = **push-to-toggle** (enter/exit, not hold), in-app-focus only, no wake word (wake-word + background = Tauri global hotkey in Rust + on-device engine, neither in stack — out of scope v1). `stop listening` = guaranteed deterministic exit. Probe mic/STT/key/transcribe/TTS at start; degraded modes fail loud, never silent.

## Symon / Aqua Color voice engine port (DECIDED 2026-06-07)

**Verdict: GO — full fold of Symon into o8.** The source is MIT-licensed, and both apps are Tauri **2.10.3** exactly (ABI/codegen parity). The STT core is genuinely zero-network and never touches o8's better-sqlite3. Not a black-box port — a **four-way split**:

- **Lift wholesale (crown jewel #1):** `helpers/speech_recognizer.swift` (Apple SFSpeechRecognizer daemon — on-device, streaming, free, zero-network, auto-chains past Apple's ~60s limit) as a Tauri **externalBin sidecar** + `stt/mod.rs` `LiveRecognizer` (std/libc/serde/tracing only). o8's `useDictation` drops `webkitSpeechRecognition` + the HTTP transcribe/polish and listens to a Rust `o8:stt-event` emit instead. **This replaces the entire prior STT plan (Gemini Live / webkitSpeechRecognition / Whisper) — the webkitSpeech "verify in signed app" gate becomes "verify the sidecar spawns + emits finals in the signed app."**
  - **Real pipeline:** LISTEN (`SFSpeechRecognizer`, *always* the live listener) → **default-on** Whisper re-transcribe of the recorded WAV (post-finalize, pre-polish; replaces Apple's raw text, **never listens**) → commands → **Gemini multimodal polish** (re-hears the *same* WAV — the only audio re-hear). The Swift helper records the 16kHz WAV **unconditionally** (`speech_recognizer.swift:818-834`).
  - **Whisper SHIPS ON (operator decision 2026-06-08 — tested, required for extreme/accented/noisy cases; NOT optional).** Lift `stt/whisper.rs` + `lib.rs:752-786 choose_final_stt_transcript`, rewired to `keys::get_key("OPENROUTER_API_KEY")` (direct OpenRouter BYOK — not the symon proxy, not the dev-gated `keys::openrouter()` accessor). Needs `OPENROUTER_API_KEY`.
- **Lift with re-namespace:** `voice_actions.rs` (PATH A — regex open-app/url/path, no LLM, instant), `agent/safety.rs` (3-tier ReadOnly/Reversible/Destructive + NEVER_DO tables, unknown→Destructive fail-safe), `agent/tools/mac_*.rs` + AppleScript/JXA helpers = the **Mac-OS convenience-action class** (open app, reminders, calendar, notes, mail, contacts). Re-pointed to o8 entitlement.
- **Copy-as-prompt-text, reimplement the host (crown jewel #2):** `polish.rs` `build_prompt`/`PolishContext`. The **~98% is a Gemini-Flash SECOND PASS** that re-hears a ~300KB FLAC of the same audio with app/window/selected-text/AX-tree/dictionary context + a hallucination guard ("spoken words beat on-screen text") + output-coverage. `should_skip_polish` short-circuits clean 3–8 word utterances to $0. Port the prompt body literally; o8 supplies the transport (its own `GEMINI_API_KEY`).
- **Do NOT port:** Symon's hosted metered-inference service (o8 already owns its hosted inference and account-service boundary), `keys.rs`/`product_mode.rs` symon coupling, the Svelte frontend (o8 reimplements the HUD in React inline-styles), `computer_use.rs`/browser daemon (defer), the 3800-line `lib.rs` spine (it's the wiring *contract* to re-implement, not code to copy).
